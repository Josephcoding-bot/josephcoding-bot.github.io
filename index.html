ARDUINO PROJECT

Smart Drawer Lock

An RFID-based drawer access-control prototype built with an Arduino Uno. The RFID-RC522 reader checks a presented tag, and a servo motor operates the locking mechanism when an authorized tag is recognized. A 16 × 2 LCD provides access-status feedback.

Designed to provide convenient, keyless access while keeping the drawer locked when an unrecognized tag is presented.
